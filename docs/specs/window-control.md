# 窗口控制设计

最后更新：2026-06-08

## 1. 目标

为 `卡厄思梦境 Windows PC 客户端` 提供稳定的窗口连接、截图与输入基础能力，作为后续识别与自动化流程的底座。

## 2. 第一阶段目标

第一阶段只关注以下能力：

- 发现目标游戏窗口
- 连接目标窗口
- 读取窗口标题、句柄、位置、尺寸
- 判断是否为支持分辨率
- 连接成功后保存一张窗口截图
- 将结果记录到日志与控制台

暂不要求第一阶段完成：

- 后台稳定输入
- 高性能连续截图
- 多窗口切换
- 多分辨率适配

## 3. 窗口连接逻辑

需要特别强调：

- “找到游戏窗口” 属于控制层问题
- “识别游戏内按钮和界面” 属于识别层问题

这两件事在实现上应明确分层，不应混在一起。

### 3.1 与图像识别的边界

第一版窗口连接逻辑不依赖图像识别。

原因：

- 连接窗口时，目标是找到一个可控制的 Windows 窗口对象
- 这一步的输入是系统窗口列表，而不是游戏截图
- 这一步主要依赖窗口标题、句柄、客户区尺寸、可见性、最小化状态等系统信息

因此，窗口连接阶段的典型流程是：

1. 枚举顶层窗口
2. 读取标题、位置、尺寸
3. 根据关键字筛选候选窗口
4. 根据分辨率筛选目标窗口
5. 输出连接结果

图像识别从窗口连接成功之后才开始介入，典型用于：

- 判断当前是否在主菜单
- 判断是否出现肉鸽入口
- 判断是否处于战斗中
- 判断是否出现胜利结算或奖励界面

也就是说：

- `窗口匹配`：不依赖图像识别
- `界面识别`：依赖图像识别

这个边界应长期保持稳定，避免将“连不上窗口”和“识别不到按钮”混为同一类问题。

建议按以下优先级识别目标窗口：

1. 窗口标题精确匹配
2. 窗口标题包含关键字匹配
3. 进程名匹配
4. 窗口类名匹配

建议程序支持：

- 自动扫描并尝试连接
- 配置文件中指定匹配关键字
- 在多候选窗口时输出候选列表
- 在日志中明确区分“窗口匹配失败”和“图像识别失败”

## 4. 连接成功后的校验项

连接成功后应立刻校验：

- 窗口是否可见
- 窗口是否最小化
- 客户区尺寸是否符合目标分辨率
- 窗口标题是否仍匹配
- 进程是否仍存活

如果校验失败，应：

- 写入 `WARN` 或 `ERROR` 日志
- 在控制台明确显示失败原因
- 不进入后续截图与识别流程

## 5. 分辨率策略

V1 当前固定只支持一个分辨率：`1920x1080`。

原因：

- 模板资源更稳定
- 点击坐标更稳定
- ROI 区域更稳定
- 可显著降低早期复杂度

第一版窗口筛选策略：

- 枚举所有可见且未最小化的顶层窗口
- 读取窗口标题与客户区尺寸
- 在程序启动时启用 DPI 感知，避免 Windows 缩放导致尺寸被虚拟化
- 先按标题关键字筛选
- 再优先选择分辨率为 `1920x1080` 的候选窗口
- 如果只有标题匹配但分辨率不符，则输出明确失败原因

第一版截图验证策略：

- 仅在窗口连接成功后执行
- 抓取目标窗口客户区图像
- 保存到 `debug/screenshots/last_window_capture.bmp`
- 在日志和控制台中输出截图保存路径

第一版输入验证策略：

- 在窗口连接和截图成功后执行
- 使用固定客户区坐标做一次点击验证
- 当前默认验证坐标为右上角菜单按钮附近 `1840,54`
- 点击前保存 `before_input_click.bmp`
- 点击后等待一小段时间，再保存 `after_input_click.bmp`
- 通过截图差异和界面变化人工确认输入是否生效

后续如需扩展，可采用：

- 多分辨率资源包
- 坐标缩放映射
- 基于锚点的相对定位

## 6. 日志与进度要求

窗口控制阶段必须输出以下信息：

- 窗口扫描开始
- 扫描到的候选窗口数量
- 最终匹配到的窗口信息
- 句柄、标题、坐标、尺寸
- DPI 信息
- 分辨率校验结果
- 连接成功或失败原因
- 首张截图保存结果
- 固定坐标点击位置
- 点击前后截图保存结果

控制台至少应显示：

- 当前阶段：窗口连接
- 当前步骤：扫描 / 匹配 / 校验
- 当前结果：成功 / 失败

## 7. 第一版输出示例

```text
[阶段] 窗口连接
[步骤] 正在扫描系统窗口
[状态] 进行中
[详情] 发现候选窗口 2 个

[阶段] 窗口连接
[步骤] 正在连接目标窗口
[状态] 成功
[详情] 已连接 卡厄思梦境 hwnd=123456 size=1920x1080
```

## 8. 第一阶段验收标准

满足以下条件即可认为窗口控制第一阶段完成：

- 程序可稳定找到目标游戏窗口
- 日志中可看到完整连接过程
- 控制台可看到实时连接状态
- 程序可正确拒绝不支持的分辨率
- 程序可在连接成功后保存首张窗口截图

## 9. 下一步

窗口连接稳定后，下一步进入：

- 输入能力验证
- 调试截图保存
